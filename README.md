# Digital Design Lab

A collection of Digital Logic Design and Verilog HDL projects developed as part of my journey in VLSI Design and Engineering.

## Objectives

- Learn Digital Logic Design
- Develop RTL Design skills
- Practice Verilog HDL
- Build FPGA-ready designs
- Create a professional VLSI portfolio

## Tools Used

- Verilog HDL
- Icarus Verilog
- GTKWave
- Git
- GitHub
